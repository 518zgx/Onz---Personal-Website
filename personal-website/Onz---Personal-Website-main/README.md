# ONZ 个人网站

一个采用赛博朋克美学风格的静态个人作品集网站，包含引导页、主页面、游戏中心和创意工具箱。

## 🔧 功能

- **引导页**：动态粒子效果和无缝页面过渡
- **主页面**：响应式个人作品集，粒子背景鼠标跟随
- **游戏中心**：6 个互动小游戏（贪吃蛇、打砖块、太空射击、记忆翻牌、2048、赛博飞鸟）
- **创意工具箱**：6 个创意工具（流场生成器、像素画编辑器、故障艺术工坊、智能调色板、分形探索器、波形合成器）

## 📁 项目结构

```
personal-website/
├── onz-intro.html      # 引导页
├── onz-main.html       # 主页面
├── games.html          # 游戏中心
├── toolkit.html        # 创意工具箱
└── CODE_WIKI.md        # 完整文档
```

## 🎨 技术栈

- 原生 HTML5 / CSS3 / JavaScript
- Canvas API
- Google Fonts (Orbitron, Rajdhani, Space Grotesk)
